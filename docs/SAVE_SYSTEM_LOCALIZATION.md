# Переклад системних повідомлень зі збереженням видимості сейвів

Користувач підтвердив 12.10.2026: повністю перекладена Xrd777
DT_SystemTextName працює й усі сейви видно, коли до базової
DT_SystemTextTranslationTable додано українські відповідники з правильною
мовною маскою англійської локалізації (біт 2).

Пакувальник тепер робить це автоматично, аналогічно до назв локацій:

```bash
./scripts/linux/repack_linux.sh dt
./scripts/linux/pack_linux.sh
```

Для останніх завантажених XML можна явно передати каталог імпорту.
Окремо запускати тестовий build_probe_en.py більше не потрібно.

Генератор tools/dt/save_system_localization.py:

- зіставляє вихідні та перекладені Name за числовими ID рядків;
- зберігає FText namespace/key, ідентичність рядків і технічні коментарі;
- додає українські Name на основі англійських записів, зберігаючи Ext та LangBits;
- не сплутує збіг написання з придатною мовною маскою: наявний російський
  варіант (Пн) із маскою 512 не замінює англійський відповідник із бітом 2;
- залишає всі оригінальні рядки таблиці відповідників байт-ідентичними;
- не генерує невідомі ID для повідомлень, відсутніх у таблиці відповідників.

Оригінальні шаблони зберігаються в tools/dt/save-localize-source/ для
Xrd777 і Astrea. Це залежності збирання; їхні JSON містять SHA-256 для
перевірки походження. Зміни джерел гри потребують повторної перевірки шаблонів.

Згенеровані ресурси потрапляють лише в робочий каталог поточного пакування.
У фінальному dist/<час>/reports/ створюються
system-save-localization-Xrd777.json та system-save-localization-Astrea.json.
Звіт показує кількість доданих записів і повідомлення без відповідного ID.
Вони можуть бути звичайними повідомленнями, які не використовуються у сейвах.

Без змін SystemTextName генератор не додає замін. Якщо ресурс виключено
правилами пакування, його відповідники не генеруються. Для явних діагностичних
збірок P3R_DIAGNOSTIC_ASSETS_FILE автоматичні конвертери залишаються вимкненими:
потрібні контрольні відповідники тоді задаються явно.

Xrd777: результат генератора байт-ідентичний перевіреному у грі прототипу
з 32 новими записами. Astrea: перевірено збереження оригіналу й підтримку
схеми; перекладену версію ще потрібно окремо перевірити у грі.

Перевірки:

```bash
python3 tests/test_save_system_localization.py
python3 tests/test_save_place_localization.py
```
