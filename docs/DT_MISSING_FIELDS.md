# Повнота експорту DT і SystemTextName

11.10.2026: оновлено 20 DT text XML та дві DT_SystemTextName зі
структурного експорту. Додано 455 текстових записів; збережено переклади
останньої тестової збірки з Downloads/translations. Технічні поля не
перекладаються: правила Crowdin вибирають role=value або старі записи без role.

Construction Site та Iwatodai Strip Mall у підказках об’єктів були відсутні
в старому Xrd777 DT_FldDungeonHitName XML (offset 0x22D8 і 0x17B6).
Однакові рядки в DailyHitName не замінюють ці окремі записи.

SystemTextName лишається у dt_xml/fstrings/, щоб не міняти шляхи Crowdin.
Новий layout=tagged-text передає імпорт структурному обробнику та перевіряє
редагованість кожного offset. Старий евристичний експорт пропускав рядки з
переносами й помилково включав деякі namespace як текст для перекладу.

Підтверджено для Xrd777 та Astrea: імпорт без змін байт-ідентичний оригіналу,
повний повторний експорт перекладених значень збігається з XML (120 і 122 поля).
SystemTextName увімкнено в тестовій збірці; роботу в грі ще має перевірити користувач.

Перед оновленням джерел Crowdin потрібно синхронізувати оновлені джерельні XML,
конфігурацію та українські переклади. Нові рядки не потрапляють автоматично в уже
створені завдання: їхній склад слід оновити після перевірки серверної синхронізації.
Не замінюйте оновлені українські XML старим експортом Crowdin, поки нові рядки
не імпортовані та не перевірені.
