# Українські назви місць і сумісність із сейвами

Зміна тільки `L10N/en/Xrd777/Field/Data/DataTable/Texts/DT_FldPlaceName`
приховувала більшість старих сейвів. Проблема відтворювалася навіть із
ASCII-правками тієї самої довжини; незмінені англійські значення в UTF-16
працювали. Дублікати в самій PlaceName не забезпечили одночасно
український інтерфейс і видимість сейвів.

Робоче рішення підтверджене користувачем у грі: українська PlaceName
та додаткові українські пари Name/Number у базовій таблиці
`Xrd777/UI/Tables/SaveDataLocalize/DT_FldPlaceNameConvert`.

## Звичайне збирання

```bash
./scripts/linux/repack_dt_text.sh
./scripts/linux/pack_linux.sh
```

Пакувальник автоматично читає перекладений Xrd777 DT_FldPlaceName,
порівнює його з оригіналом і створює конвертер у робочій папці збірки.
Оригінальні рядки конвертера всіма мовами залишаються побайтово
незмінними. Українські відповідники додаються з тими Number, які вже
визначені грою. Вони не завжди збігаються з прямими Index PlaceName,
тому зв'язок установлюється через оригінальні англійські назви.
Повторне пакування щоразу починає з чистого шаблону й не накопичує дублів.

Шаблон конвертера:
`tools/dt/save-localize-source/Xrd777/UI/Tables/SaveDataLocalize/DT_FldPlaceNameConvert.uasset`.
Поруч лежить опис оригінального ресурсу та SHA-256. Генератор:
`tools/dt/save_place_localization.py`. Звіт кожної збірки:
`dist/<час>/reports/save-localization.json`.

Конвертер додається тільки коли Xrd777 PlaceName входить у комплект.
Діагностичний режим P3R_DIAGNOSTIC_ASSETS_FILE вимикає автогенерацію,
щоб контрольні проби не отримували додаткових змін.
DT text увімкнені за замовчуванням; колишній P3R_INCLUDE_DT_TEXT=1
більше не потрібний. DT_SystemTextName та некоректний DT_DlcBgm
залишаються у списку виключень.

## School Building

Сканер помилково приймав Index=2 і початок наступного property tag за
короткий технічний FString `o`, після чого пропускав реальне Name
`School Building`. Технічні евристичні збіги тепер не пропускають байти
наступного поля. Новий вузол із offset 0xC2C додано до існуючого XML
з перекладом «Будівля школи». Інші переклади збережені.

## Перевірки

```bash
python3 tests/test_save_place_localization.py
python3 tests/test_dt_batch_preflight.py
python3 tests/dt_nested_regression.py
```

Перевіряються незмінність оригінальних мовних рядків, правильні
українські відповідники Number, унікальні ключі нових рядків,
відновлення School Building і побайтова тотожність імпорту без змін.
Після нового перекладу треба перевірити список сейвів і назви локацій
у грі. Самі файли збережень інструменти не редагують.
