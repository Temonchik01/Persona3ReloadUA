# Прогрес перекладу текстур

Реєстр: translation-progress.csv. Один рядок — один DDS, path відносний до dds/.
Відкривайте як UTF-8 CSV з роздільником кома у LibreOffice Calc або редакторі.

Статуси:
- unknown — статус ще не визначено; це не означає, що файл не перекладений;
- todo — потрібно перекласти;
- in_progress — у роботі;
- translated — переклад текстури завершено;
- reviewed — переклад перевірено;
- tested — вигляд перевірено у грі.

Позначки ^ з папок Field, TartarusMap, TimeChange, Title та TownMap перенесено
у translated для всіх DDS усередині цих папок. Решта отримали unknown.
Автор не заповнений, щоб не приписувати роботу без підтвердження.
Реєстр охоплює поточні DDS у Xrd777/UI. Нові файли додавайте окремими рядками.
Не змінюйте назви ігрових папок/файлів для позначення прогресу.
CSV не читається Crowdin чи пакувальником і не впливає на збирання.

Після виправлення назв повторіть імпорт DDS:

```bash
./scripts/linux/repack_dds.sh "$PWD/dds"
./scripts/linux/pack_linux.sh
```

Це не прибирає старі зібрані ресурси автоматично. Відсутні локалізовані
копії ресурсів у missing-assets.json потрібно дослідити окремо.
