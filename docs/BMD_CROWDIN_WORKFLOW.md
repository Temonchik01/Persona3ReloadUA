# Англійські джерела BMD і українські переклади

`xml/` — джерельні XML для Crowdin. Репліки, варіанти відповіді та назви
мовців відновлено з оригінальних англійських uasset у `tools/dds_l10n/source/`.
Структуру поточних робочих XML, ідентифікатори та атрибути збережено.

`translations/uk/xml/` — українські XML для збирання. Під час розділення
сюди перенесено поточні робочі XML, включно з останніми локальними правками.
Вони мають пріоритет над попередніми версіями цих самих файлів у цій папці.

Не перекладайте XML у `xml/`: інтеграція сприймає їх як джерельну мову.
Редагуйте переклади в Crowdin або у `translations/uk/xml/`.

Linux і Windows імпортери BMD типово читають `translations/uk/xml/`:

```bash
./scripts/linux/repack_linux.sh bmd
./scripts/linux/pack_linux.sh
```

Явно переданий каталог XML має пріоритет над типовим шляхом.

В інтеграції GitHub джерельною гілкою залишається `main`, службовою —
`l10n_main`. Джерела: `/xml/**/*.xml`. Переклади:
`/translations/%two_letters_code%/xml/**/%original_file_name%`.

Після push синхронізуйте інтеграцію та перевірте Preview одного файла
з Battle: вихідна репліка має бути англійською, український текст — перекладом.
Збереження Git-конфігурації не підтверджує результат серверної синхронізації.
