# Усі шляхи DT XML для Crowdin

Цей список містить усі DT XML, наявні в репозиторії. Він не гарантує повноту всіх ресурсів гри.

## Translatable elements

Для text: `/P3RDataTableText/Text/Translation`.
Для fstrings: `/P3RDataTableFStrings/String/Translation`.

У спільному полі Parser configuration можна вказати обидва XPath через кому:

```text
/P3RDataTableText/Text/Translation,/P3RDataTableFStrings/String/Translation
```

Батьківські вузли та Source не додаються. Складні предикати ролей прибрано після підтвердженого користувачем Nothing to translate.

Translate content увімкнено; Translate attributes і Content segmentation вимкнено.
