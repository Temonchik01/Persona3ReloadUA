# Компактне пакування на Linux

Закрийте гру. Підготуйте ресурси:

```bash
./scripts/linux/repack_linux.sh bmd
./scripts/linux/repack_linux.sh dt
./scripts/linux/repack_dds.sh "$PWD/dds"
./scripts/linux/pack_linux.sh
```

Типовий вхід — UnrealEssentials/ з деревом P3R/Content/...
Для піднабору вкажіть папку з цим деревом:

```bash
./scripts/linux/pack_linux.sh /path/to/UnrealEssentials
```

## Що входить у мод

- Тільки змінені uasset та їхні потрібні ubulk/uptnl.
- Записи таблиці пакетів лише для включених ресурсів.
- Ідентифікатори залежностей, які гра читатиме з оригінальних архівів.
- Відповідні мовні перенаправлення з оригінальної таблиці.
- Усі потрібні додаткові локалізовані копії; вони не видаляються.
- Один PAK зі шрифтами; решта PAK мають порожній індекс монтування.

Повні контейнери гри більше не розпаковуються й не копіюються.
Незмінені ресурси пропускаються за SHA1 оригінального індексу UE4;
список — unchanged-assets.json. Регістр ігрових шляхів нормалізується
за оригінальним каталогом без перейменування файлів мода.

Таблиця UE4 Initial читається з обмеженнями кількості та розміру:
зберігаються оригінальні імпорти, записи тільки для включених ресурсів,
культурні й пакетні перенаправлення тільки для включених цілей.
Лічильники експорту перевіряються за Zen-заголовками. Retoc пише нові
UTOC/UCAS і перевіряє цілісність; скрипт порівнює SHA256 ресурсів.

## Додаткові локалізовані ресурси

Відсутні L10N-копії отримують шаблони з L10N/en або базового Content.
Retoc перетворює вибрані шаблони в legacy, створює метадані нових
локалізованих шляхів через to-zen. Готовий вміст мода підставляється
без зміни даних; лічильники експорту узгоджуються з ним. Перевірка
включає повторне перетворення всіх додаткових ресурсів у legacy.
Тестувалося на P3R UE4.27; невідомий формат/шаблон зупиняє збирання.
Ідентифікатори, шаблони та хеші записані в additional-assets.json.

## Установлення

Результат для встановлення: dist/<час>/mod/. Рівно три файли:
pakchunk999-Ukrainian_P.pak, .utoc та .ucas.
Після повідомлення Completed перевірте наявність BUILD_COMPLETE.json.
Скопіюйте ТІЛЬКИ три .pak/.utoc/.ucas із підпапки mod/
в P3R/Content/Paks/~mods. Проміжні UA00, UA01 тощо та UAAdded з батьківської папки встановлювати
не потрібно: їхній вміст уже об’єднаний у mod/. Не копіюйте raw-* або інші проміжні папки та оригінальні архіви.
Попередній комплект приберіть із ~mods перед встановленням нового.
Запустіть гру через Steam з English без Reloaded-II.

Новий компактний комплект ще потребує перевірки в грі: контроль
цілісності не доводить правильного відображення всіх екранів.

## Налаштування

Шляхи можна задати в config.local.env (приклад у корені) або командою:

```bash
RETOC=/path/to/retoc GAME_PAKS=/path/to/P3R/Content/Paks \
FONT_PAK=/path/to/fonts.pak P3R_PACK_MEMORY_MB=1536 \
P3R_PACK_TIMEOUT=900 ./scripts/linux/pack_linux.sh
```

Типовий retoc: tools/iostore/bin/retoc (локальна папка, не в Git).
Типові шрифти: tools/iostore/fonts.pak; незмінені ufont перевіряються
за tools/iostore/font-reference. Для змінених шрифтів потрібен окремо
зібраний FONT_PAK. Linux-конвертація DDS використовує libtexconv.so.
AES-ключ уже заданий у Python-скрипті.
Retoc працює послідовно з обмеженням пам'яті та часу кожної команди.
Тимчасові результати створюються в build/pak-builds/<час>/. Після успішної
перевірки фінального контейнера й ZIP вони автоматично видаляються.
Готові файли та звіти залишаються в dist/<час>/. Невдала збірка
зберігає робочі файли для діагностики; резервні копії не створюються.

## Тимчасове виключення DT text

До виправлення імпортера ресурси, перелічені в
config/build-exclusions.json, виключаються з мода у базовому Content
і всіх L10N-культурах. XML та зібрані uasset не видаляються.
Звіт кожного збирання: excluded-assets.json. Гра використовує свої
оригінальні DT замість цих ресурсів. BMD, текстури й DT fstrings
не виключаються цим правилом.

Після виправлення імпортера потрібно перезібрати DT, а тоді вимкнути
enabled у конфігурації. Для контрольованого тесту можна явно задати
P3R_INCLUDE_DT_TEXT=1; до виправлення це поверне проблемні ресурси.

## Об’єднання в три файли

Фінальний етап об’єднує компактні raw-ресурси, записи пакетів, імпорти
та мовні перенаправлення. Ідентифікатори й дані ресурсів зберігаються;
залежності читаються грою з її оригінальних контейнерів. Для додаткових
локалізованих копій культура визначається за фактичним L10N-шляхом,
а не за мовою шаблону. Конфлікт ідентифікаторів або даних зупиняє білд.
Retoc перевіряє фінальний контейнер; після повторного розпакування
скрипт порівнює SHA256 усіх ресурсів із вхідними компактними частинами.

Окремі контейнери потрібні лише як проміжні дані до перевірки фінального мода.
Для тестувальника передавайте лише три файли з mod/. Перед тестом
приберіть старі комплекти з ~mods, щоб вони не
перекривали новий пакет. Перевірте діалоги, меню, текстури, шрифти
та завантаження збереження. Проблемні DT text поки виключені.
