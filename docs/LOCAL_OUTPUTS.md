# Локальні результати та робочі матеріали

Ці папки не додаються в Git. Джерела `xml/`, `dt_xml/`, `dds/`,
`translations/` і конфігурація Crowdin залишаються на місці.

| Папка | Вміст | Очищення |
|---|---|---|
| `build/pak-builds/<час>/` | Робочі контейнери поточної/невдалої збірки | Автоматично лише після перевірки та публікації результату |
| `build/logs/` | Журнали імпорту XML/DDS | Вручну, коли діагностика більше не потрібна |
| `build/tests/` | Згенеровані результати перевірок | Можна повторно створити тестами |
| `build/dt-tool/` | Проміжні файли C# | Можна повторно створити збиранням інструмента |
| `dist/<час>/mod/` | Три файли для гри: pak, utoc, ucas | Вручну після завершення тестування версії |
| `dist/<час>/Persona3ReloadUA.zip` | Перевірений ZIP тільки з трьома файлами | Вручну |
| `dist/<час>/reports/` | Метадані, списки ресурсів і журнали перевірки | Зберігаються разом із результатом |
| `.cache/wine-build-prefix/` | Wine-середовище для Windows-інструментів | Не чіпати під час роботи Wine |
| `.cache/dotnet-home/`, `.cache/nuget/` | Кеші .NET | За потреби; наступне збирання може повторно створити їх |
| `workspace/` | Експорти та редаговані XML/DDS | Автоматично не видаляється |

Пакувальник не перезаписує попередню версію в dist. Кожна збірка має
окремий час. Після успішної перевірки фінального UTOC/UCAS та ресурсів
пакувальник створює ZIP, перевіряє SHA-256 його вмісту, публікує результат
і видаляє робочу папку конкретної збірки. Якщо публікація зупинена,
може залишитися `dist/<час>.pending/`: це незавершений результат,
його не слід встановлювати в гру.

Скрипти не створюють резервних копій uasset або старих модів.
Git зберігає лише додані й закомічені файли; редаговані експорти з
workspace не є частиною історії Git. Готові зміни для перекладу переносіть
у відповідні `xml/`, `dt_xml/` або `dds/` перед комітом.

Під час міграції з artifacts робочі експорти перенесені в workspace,
завершені комплекти з трьома файлами — в dist, проміжні дані завершених
об'єднаних збірок видалені. Старі необ'єднані збірки доступні в
`build/legacy-pak-builds/`; це історичні багаточастинні результати,
не рекомендований комплект для встановлення. Старі локальні резервні
копії прибрані відповідно до обраного режиму без бекапів.
