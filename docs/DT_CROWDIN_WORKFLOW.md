# Джерела і переклади DT для Crowdin

`dt_xml/` містить джерельні XML: у кожному записі значення `Translation`
дорівнює оригінальному `Source`. Це необхідно для поточного `crowdin.yml`,
де перекладним елементом обрано `Translation`.

`translations/uk/dt_xml/` містить українські XML із тією самою структурою,
оригінальним `Source` та українським `Translation`. Сюди інтеграція Crowdin
експортує український переклад. Наявні переклади збережені під час розділення.

Не перекладайте джерела в `dt_xml/`. Редагуйте український переклад у Crowdin
або відповідний XML у `translations/uk/dt_xml/`. Після оновлення структури
джерела оновлюйте також структуру українського XML, зберігаючи переклади.

Linux-скрипти DT та `scripts/windows/repack_dt.bat` типово читають
`translations/uk/dt_xml/`. Явний каталог для Linux має пріоритет над типовим.

Збирання лише DT text:

```bash
./scripts/linux/repack_dt_text.sh
```

Збирання всіх DT:

```bash
./scripts/linux/repack_linux.sh dt
```

Після імпорту:

```bash
./scripts/linux/pack_linux.sh
```

Комітьте джерела і відповідні переклади разом. `crowdin.yml` не потребує
зміни: він уже розділяє ці шляхи. Зміни набудуть чинності в інтеграції після
push у `main` і синхронізації Crowdin; локальне розділення не підтверджує
результат синхронізації на сервері.
