# Текстури

- `dds/` — готові DDS зі шляхами `Xrd777/...` та `Astrea/...`.
- `png/` — PNG, експортовані редактором для збирання. Ті самі шляхи та назви.
- `sources/` — робочі PSD, XCF, KRA, PCRAFT та інші вихідники з шарами.
- `originals/` — збережена колекція оригіналів, у збиранні не використовується.

У повному збиранні готовий DDS має пріоритет над однойменним PNG.
PNG конвертується лише за відсутності DDS. Щоб включити свіжі зміни PNG у
повний мод, спочатку натисніть «PNG → DDS». У тесті вибраних текстур навпаки:
PNG має пріоритет, щоб художник одразу перевіряв останній експорт.
Сам PSD/XCF не потрапляє у мод. Дати файлів не визначають пріоритет.

Конвертація використовує звичайну якість BC7 (`normal`) та бере параметри базового UAsset гри та зберігає результат у
`workspace/texture-dds-cache`. Під час білда DDS підставляються у тимчасову папку `build/`.
Наступні білди повторно використовують перевірений кеш для незмінених PNG.
Кнопка «PNG → DDS» у GUI явно оновлює відповідні DDS у `texture/dds`, щоб
підготувати їх до збирання заздалегідь. Помилка конвертації зупиняє імпорт; старий DDS не
підставляється. Звичайний білд не змінює вихідні DDS та PNG; кнопка
попередньої конвертації оновлює тільки відповідні DDS.

Не кладіть сюди PNG-прев'ю, які не повинні брати участі у збиранні: зберігайте
їх у `workspace/`. У повному білді наявний DDS використовується незалежно від наявності PNG.

Linux: `./dev/scripts/linux/build_mod.sh` або `./dev/scripts/linux/repack_dds.sh`.
Windows: `dev/scripts/windows/repack_dds.bat` використовує той самий вибір PNG/DDS;
запуск оновленого процесу на Windows ще потребує перевірки.

Явний аргумент з іншою папкою у `repack_dds.sh` імпортує лише DDS із цієї папки.
