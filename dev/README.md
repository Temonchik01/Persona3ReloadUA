# Інструментарій проєкту

- `scripts/linux/` — команди збирання й імпорту на Linux.
- `scripts/windows/` — відповідні команди Windows.
- `tools/` — компілятори, конвертери та оригінальні ресурси для імпорту.
- `instruments/` — вихідний код C# інструментів.
- `gui/` — графічний застосунок для учасників команди.

Основний запуск із кореня репозиторія:

```bash
./dev/scripts/linux/build_mod.sh
```

Скрипти самі визначають корінь репозиторія. Переклади залишаються в
`translations/`, текстури — у `texture/`, результати — у `dist/`,
тимчасові файли — у `build/`. Шляхи джерел Crowdin не змінені.
