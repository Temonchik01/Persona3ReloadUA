# Збирач мода з графічним інтерфейсом

Linux: `./dev/scripts/linux/build_gui.sh`.
Windows: подвійний клік на `dev/scripts/windows/build_gui.bat`.

Потрібні Python 3.11+ з Tkinter і Pillow, інструментарій репозиторія та
встановлена гра. На Windows вкажіть Windows-версію `retoc.exe`; Linux-бінарник
з репозиторія на Windows не працюватиме. Повний Windows-білд потребує .NET 8 SDK.
Після встановлення Python на Windows можна запустити
`dev/scripts/windows/install_gui_dependencies.bat`, щоб встановити Pillow.
Повний Linux-білд використовує наявні Bash/Wine/.NET-скрипти.

## Тест текстур

1. Вкажіть папку `P3R/Content/Paks`, retoc і пакет шрифтів.
2. Виберіть рядки текстур; Ctrl/Shift дозволяють вибрати кілька.
3. За потреби підставте свій PNG/DDS для конкретного рядка. Назва довільна:
   шлях ресурсу визначає вибраний рядок. Ця підстановка діє лише на тест текстур.
4. Натисніть «Зібрати мод». Використовується окрема тимчасова папка, робочі
   текстури й повний переклад не перезаписуються.
5. «Відкрити результат» показує ZIP і папку `mod` з трьома файлами.

У тесті вибраних текстур PNG автоматично береться з `texture/png`, за його відсутності — DDS із
`texture/dds`. PSD/XCF потрібно спочатку експортувати в PNG.
У повному моді DDS має пріоритет; PNG конвертується лише за відсутності DDS.
Після редагування PNG перед повним білдом натисніть «PNG → DDS».
Усі PNG конвертуються зі звичайною якістю BC7 (`normal`), включно з тестами.
Кнопка «PNG → DDS» поруч із «Оновити список» заздалегідь компілює **всі PNG
з texture/png** і оновлює відповідні файли в `texture/dds`. PNG залишаються
незмінними; підставлені зовнішні файли ця кнопка не публікує в репозиторій.
Для цієї операції не потрібні гра чи retoc. Вона працює у фоні й підтримує
скасування. «Відкрити результат» показує папку готових DDS.

Конвертація також зберігається у `workspace/texture-dds-cache`. Звичайний білд
і тест вибраних текстур використовують той самий кеш. Зміна PNG, оригінального
UAsset/ubulk, конвертера, Pillow чи платформної бібліотеки спричиняє нову
конвертацію; незмінені файли не стискаються повторно. Видалення кешу безпечне:
наступне збирання просто створить його знову. Помилка конвертації не підміняється
старим DDS, а наявний робочий DDS оновлюється лише після успішної операції.
Тестова збірка містить лише вибрані текстури та пакет шрифтів. Вона призначена
для окремої перевірки: не додавайте її поверх іншого пакета з такими самими
іменами файлів.

## Повний мод

Використовує переклади з `translations/uk`, текстури з `texture` та звичайний
пакувальник із виправленнями сейвів і висоти діалогів. Підстановки окремих
файлів у таблиці не застосовуються в цьому режимі.

Журнали й опис завдання: `build/gui`. Налаштування: `workspace/gui-settings.json`.
Кнопка скасування завершує дерево процесів збірки. Гру потрібно закрити перед
збиранням. Програма не встановлює мод і не змінює файли гри автоматично.

Windows обмежує час запуску retoc; ліміт пам'яті через prlimit застосовується
тільки на Linux. Windows-запуск ще потребує перевірки на реальній системі.
Це початкова версія, не окремий самодостатній EXE з усіма залежностями.

## Фільтри списку текстур

Пошук поєднується з фільтром формату (Усі / PNG / DDS), датою (Змінено /
Вперше виявлено), періодом (Увесь час / Сьогодні / 7 днів / 30 днів) та
сортуванням «Спочатку нові». Формат і дата стосуються фактичного вхідного
файлу, включно з підставленим PNG/DDS. Дата показана в окремій колонці.

«Вперше виявлено» — час першого оновлення списку з цим файлом, записаний у
`workspace/texture-discovery.json`. Це не дата копіювання чи створення файла:
при першому запуску наявні файли отримають поточну дату виявлення. Для
історичних змін використовуйте «Змінено». Після додавання файлів натисніть
«Оновити список». Фільтри не змінюють склад повного мода або кнопки
«PNG → DDS» (вона й надалі обробляє всі PNG).
